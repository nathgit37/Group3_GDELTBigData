# Group3_GDELTBigData

## Overview

This project proposes a Cluster-Aware PageRank framework for analyzing large-scale global event networks using GDELT data.

The framework combines:

- Integrating data through PySpark
- PCA dimensionality reduction
- K-Means clustering
- Country interaction network 
- Weighted PageRank
- Cluster-aware PageRank

## Dataset

Source:

GDELT Global Events Database

Time period:

January 2025 – April 2026
